# ⑦ AI を活用した記事制作・運営フロー

いまの仕組み(Claude の下書き → tools/check.py → 本人の添削 → Canva の画像)を土台に、集客・販売・分析までを週のリズムにします。
原則は「AI は手足、判断は人」【ぽにょ・らっこ・かけち・うと・ニートパパ・SHIFT AI】。経験談・数値・安全の最終確認と、note への投稿は本人が行います。
※AI 活用の動画4本のうち2本【ニートパパ・SHIFT AI】を反映済み。残り2本【うと・ひらかわ】を読んだら見直します。
いまの CLAUDE.md・templates・tools/check.py は、動画でいう「指示書」(読者・トーン・構成・禁止語を書いたファイル)にあたり、すでにできています【SHIFT AI】。

## 1. 週のリズム(無料の連載を週3本出す場合の例)

| 曜日 | やること | Claude | 本人 |
|---|---|---|---|
| 月 | 計画 | progress.md・先週の数字・需要の調査をもとに、今週の3本と SNS のテーマ、有料記事の進め方を提案 | 承認・入れ替え(5分) |
| 火 | 下書き | 3本の下書き(check.py で確認したあと、「別の編集者の視点」で事実の怪しい所・言いすぎ・読みにくさを見直す)。見出し画像と本文の図を Canva で作成。記事ごとの SNS 投稿案を5〜10本 | なし |
| 水〜木 | 添削 | 本人の音声入力(経験談)を整えて差しこむ。指摘された所を直す | 添削(1本30〜45分)、経験談を音声で話す(1本5〜10分)、数値・安全の確認 |
| 金〜日 | 公開 | 公開順と導線(関連回・有料記事への案内)の最終チェック | note に貼って公開(1本10分)、SNS を予約投稿 |
| 日 | 数字と振り返り | 週の数字を表にまとめ、「見られていない/買われない/反応が薄い」に分けて改善案を出す | note のダッシュボードの数字を写す(10分) |

## 2. Claude への頼み方(よく使う作業に足すもの)

| 頼み方 | Claude がすること |
|---|---|
| 「次の3本を書いて」 | いまの決まりどおり(下書き、check.py、progress.md の更新) |
| 「○番の画像を作って」 | 画像の決まりどおり(Canva で見出し画像と本文の図) |
| 「○番の SNS 投稿を作って」 | 記事から Threads・X の投稿案を5〜10本。種類(悩みの言い当て/数字のコツ/旬/告知)を分け、数値は記事で確認済みのものだけ |
| 「需要を調べて(テーマ)」 | X・Threads・note の反応の多い投稿と有料記事を集め、悩みを分類して research/ に記録 |
| 「有料記事『○○』を企画して」 | 骨格(変化の約束 → 共感 → 道のり → 最初の一歩)の構成案を出す。承認後に章ごとに本文 |
| 「今週の数字を分析して」 | 数字の表から、直す記事・直す所(タイトル/無料部分/中身)と案、次に書くテーマの優先順位を出す |
| 「経験談を整えて」 | 本人が音声入力で話した文を、作り話を足さずに読みやすく整え、記事のどこに入れるかを提案 |
| 「インタビューして(テーマ)」 | 記事や有料記事に必要な経験・考え方について、Claude から本人に質問を5〜10個出す。答えを素材としてためる(よく聞かれる質問への答えは、トーンの材料にもなる)【SHIFT AI・ニートパパ】 |
| 「○番を見直して」 | 別の編集者の視点で、事実の怪しい所・言いすぎ・読みにくい所を、場所を挙げて指摘する。数値・安全は本人の確認へ回す【SHIFT AI】 |

## 3. リポジトリに足すとよいもの(提案)

```
sns/            記事ごとの SNS 投稿案(例:004_塩もみ_sns.md)
data/stats.csv  週ごとの数字(記事、ビュー、スキ、有料記事のビュー、購入数、売上)
research/demand/ 需要の調査の記録(検索した言葉、反応の多かった投稿の要点)
products/       有料記事の原稿(articles/ と同じ形。価格と販売期間の欄を足す)
```

- tools/check.py に、記事の最後の「関連回・有料記事の案内」があるかを確かめるチェックを足す
- 数字は note に API がないので、本人がダッシュボードから写す(Google スプレッドシートでもよい。Claude は連携で読める)

## 4. 自動にしないこと

- note への投稿(公開 API がない。ブラウザの自動操作は規約・安全の面で避ける)。Claude in Chrome で下書きに入れるやり方【SHIFT AI】は、本人のパソコンでの設定と note の規約の確認が必要なので、将来の選択肢にとどめる
- 経験談の中身(作り話にしない)
- 数値・安全・健康に関わる記述の最終確認
- 有料記事の価格と販売の最終決定
- SNS の返信・やり取り(人と人の関係なので本人が行う)

## 5. 定期実行(Claude のルーティン)の候補

- 毎週月曜の朝:「今週の計画」を作って知らせる
- 毎週日曜の夜:「数字を入力してください」と知らせ、入力があれば分析する
- 季節の変わり目:旬の回の入れ替え候補を出す(topics.md の「旬の回を入れ替えるときの注意」に従う)
- ※作るときは本人の承認を得てから設定する
