# ③ 競合との差別化戦略

## 1. 競合の整理(research/food_genre_on_note.md より)

| 競合のタイプ | 例 | 売っているもの | 強み |
|---|---|---|---|
| 料理家のレシピ型メンバーシップ | きじまりゅうた(月800円)、星野奈々子(月880円)、Yuu(月580円) | 限定レシピ・レシピの PDF | 知名度、レシピの数、写真 |
| 料理の理屈を語るシェフ | シェフのタカハシ(メンバーシップ、価格不明) | ショート動画では語れない理屈の解説 | 動画で人気、「公邸料理人」という肩書き |
| 料理教室型 | 大原千鶴(メンバーシップ) | 月1回のオンライン教室、質問への回答 | テレビでの知名度 |
| 食のエッセイ・日記 | note の料理ページの多くの記事 | 無料の読み物 | 共感、季節感 |

## 2. 味のたねあかしの差別化の軸(分析者の提案)

1. **「レシピを売らず、レシピがいらなくなる理屈を売る」**
   - レシピ型の競合は、レシピの数と写真で勝負している。こちらは「重さの何%」「温度」など、自分で味を決められるようになるものさしを売る
   - 読者に約束する変化:「レシピを見ても毎回味が違う」→「どんな料理でも、自分で味を決められる」

2. **「100回の教科書」という体系**
   - 単発の記事ではなく、塩 → 火入れ → うま味 → 油 → 味の組み立て → 香り → 食材別 → 献立の順に積み上がる連載。回をまたいで「第○回でお話しした」とつながる
   - 有料マガジンや章ごとのまとめにしやすい(かけちの「3本がつながる設計」、うとの「マガジンでまとめる」)

3. **数値と安全の正確さ**
   - 温度・時間・塩分を、料理人の本人が確かめてから出す(確認の印の仕組み)。AI の量産記事が増えるなかで、「この人の数字は信用できる」が強みになる
   - note のおすすめ表示は一次情報・体験を重視する方向だと報じられている(二次情報)。本人の経験談を作り話にしない決まりは、この流れとも合う
   - 「経験していない分野を AI でまとめた記事は長く売れない」【ひらかわ】、「実体験・検証・失敗の記事が評価される」【ニートパパ】。料理人の15年の経験と、台所で実際に試した結果(本人が試したものだけ)を書けることが、AI の記事との一番の違いになる

4. **プロの当たり前を、家庭の言葉に**
   - ねこ太の「自分には当たり前すぎることほど、価値がある」。料理人が無意識にしていること(塩を量る、下ごしらえの意味、火を止める時機)を言葉にする
   - 専門用語を使わず、「なぜ」を一つずつ説明する(かけちの「大手の発信が難しくてついていけない人を狙う」)

5. **旬と結びつける**
   - 10〜11月の旬の食材を毎回の題材にする。季節の話題は note の料理ページでも目立つ場所に出ていた
   - 旬の有料記事は「その季節だけ」の期間限定にでき、煽りに見えない希少性になる(らっこの希少性)

6. **顔・店名を出さない代わりの信頼のつくり方**
   - 「調理歴15年の料理人」という一言と、説明の深さ・正確さで信頼してもらう
   - 自己紹介記事は「料理を始めたころにつまずいたこと → 理屈がわかった瞬間 → 今」の流れで、本人の実話で書く(かけちの「ダメだった過去 → 出会い → 今」)

## 3. やらないこと(差別化を崩さないために)

- レシピの数で競わない(写真・動画の量で負ける)
- 煽り・誇大な表現をしない(「必ず」「絶対」「誰でも」など)
- 健康・効能をうたわない(医療・栄養の専門ではないため)
- 大手の真似をした記事を量産しない(ぽにょ:読者は大手から買う)
