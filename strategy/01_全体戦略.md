## 1. ひとことで

**無料の連載「味のたねあかし」で、料理の"理屈"に興味を持った読者を集め、「レシピがなくても味が決まる」ための有料記事を、入口 → 本命 → まとめの順に売る。メンバーシップは常連さんができてから。**

## 3. 戦略の柱

1. **ジャンルと位置(②)**:料理は「大きい市場」ではない。だから、毎日の悩み(味つけ・失敗)と、忙しさ・旬に絞る
2. **差別化(③)**:レシピではなく「自分で味を決めるものさし」を売る。100回の教科書という体系、数値と安全の正確さ、顔を出さずに知識の深さで信頼してもらう
3. **商品(④)**:最初の有料記事は「塩分%早見表」。旬の「秋冬の下ごしらえ帳」を期間限定で。本命は「味つけ設計図」
4. **導線(⑤)**:無料の連載 → 自己紹介記事 → 入口 → 本命 → マガジン。どこも切らさない【かけち】
5. **SNS(⑥)**:Threads で毎日、悩みの言い当てと理屈の一言。X は需要の調査。フォロワー数より保存と note への移動を見る
6. **AI(⑦)**:Claude が手足(下書き・画像・投稿案・分析)、本人が判断(経験談・数値・安全・価格・公開)
7. **計画(⑧〜⑩)**:最初の目標は月1万円(3〜6か月目の見立て)。月5万円・10万円は、有料記事の積み上げとメンバーシップで段階的に

## 4. 動画から取り入れること・取り入れないこと

| 取り入れる | 取り入れない(または慎重に) |
|---|---|
| 需要から逆算する、1つの悩みに絞る | 恋愛・副業ジャンルの売上例を目標にする |
| 単価×人数で目標を分解する | 500円以下の低単価で件数を追う |
| 商品を先に作る、1本目を売れるまで直す | 需要を確かめずに新しいテーマを次々に出す【シズマの失敗】 |
| 潜在層向けの無料記事と、記事どうしのつながり | 「SNS なしで月100万円」のような根拠の弱い主張 |
| 自己紹介記事(本人の実話) | 経験談の作り話、誇大な実績の演出 |
| 季節に合わせた期間限定(正直な理由のある希少性)【らっこ】 | 煽りの強いローンチ、毎日の「売れました」連投 |
| AI は手足、判断は人 | AI への丸投げ(電子ゴミになる)【ぽにょ・うと】 |
| AI は聞き手:本人が話し、Claude が整理する(料理人の15年の経験が土台)【ひらかわ】 | 経験のない分野を AI に調べさせて書く【ひらかわの指摘】 |
