# ⑨ 初期費用・月額費用・想定作業時間

## 1. 初期費用

| 項目 | 費用 | 備考 |
|---|---|---|
| note・Threads・X のアカウント | 0円 | メールアドレスがあれば始められる【らっこ】 |
| パソコン | 0円(手持ち) | スマホだけでも書けるが、添削や貼り付けはパソコンが楽【うと】 |
| はかり(0.1g 単位)・温度計 | 0円〜(任意) | 記事の検証や写真に使う。持っていれば不要 |
| 合計 | 0円から始められる | |

## 2. 月額費用

| 項目 | 費用 | 必要か |
|---|---|---|
| note | 0円 | 予約投稿をするなら noteプレミアム 月500円(公式ヘルプ)。メンバーシップは無料で開設できる |
| Claude | いまの契約のまま | すでに Claude Code で運用中 |
| Canva | 0円〜 | 無料でも使える。AI の画像生成の回数や機能に制限がある場合は有料プラン(料金は Canva 公式で確認) |
| SNS の予約投稿ツール(Buffer など) | 0円〜 | 無料プランから。手動でもよい |
| 音声入力 | 0円〜 | スマホや PC の標準機能でよい。Typeless などは任意【ひらかわ】 |
| 合計 | 0〜500円+α(いまの Claude の契約は別) | |

売上にかかる手数料:カード決済なら売上の約15%(事務手数料5%+利用料10%)、振込1回270円。

## 3. 想定作業時間(無料の連載を週3本+SNS 毎日の場合)

| 作業 | 本人 | Claude |
|---|---|---|
| 週の計画の承認 | 5分 | 計画づくり |
| 下書き・画像・SNS 投稿案 | 0分 | 自動 |
| 添削・数値と安全の確認 | 1本30〜45分 × 3本 = 約2時間 | 指摘の整理 |
| 経験談を音声で話す | 1本5〜10分 × 3本 = 約30分 | 整える |
| note への貼り付け・公開 | 1本10分 × 3本 = 30分 | 最終チェック |
| SNS の確認・投稿 | 1日15分 × 7日 = 約1時間45分 | 投稿案 |
| 数字の入力 | 10分 | 分析・改善案 |
| 合計(本人) | 週 約5時間 | |

- 有料記事を作る週は、本人の確認に +2〜3時間(数値・安全の確認を丁寧に)
- 30日の検証動画では、慣れないうちは記事1本に9時間かかった例がある【シズマ】。最初の数週間は時間が多めにかかる前提で
- 本人の時間が足りない週は、連載の本数を減らしてよい(数より正確さ)
