# ⑩ 月1万円・月5万円・月10万円を目指す現実的な計画

金額は手取り(カード決済で計算。事務手数料5%・利用料10%を引き、振込手数料270円を月1回)。
「必要な件数」は計算で出せますが、「何人に見てもらえば何件売れるか(購入率)」は動画にも公式データにもなく、不明です。最初の有料記事を出してから実際の購入率を測り、必要なビュー数を逆算します。
達成時期は分析者の推測です。料理は動画で挙がった「大きい市場」ではないので、恋愛・副業ジャンルの数字をそのまま当てはめていません。

## 月1万円(最初の目標)

| 商品 | 価格 | 月の件数 | 手取り |
|---|---|---|---|
| 入口の有料記事(塩分%早見表など) | 980円 | 7件 | 約5,870円 |
| 本命「味つけ設計図」 | 2,980円 | 2件 | 約5,100円 |
| 合計(振込手数料のあと) | | 9件 | 約10,700円 |

- 入口だけなら980円を月13件
- 必要なもの:有料記事2〜3本、無料の連載20本ほど、SNS で需要を確かめた悩み
- 時期の見立て:3〜6か月目(推測)
- 大事なこと:最初の1件を売ることが一番むずかしい【ひらかわ】。売れなかったら、原因を「見られていない/買われない/反応が薄い」に分けて直す【ねこ太】

- 大事なこと:SNS なしでは月2〜3万円が上限という見立てがある【ぽにょ】。Threads・X で需要を確かめ、つながる仕組みが必要

## 月10万円

| 商品 | 価格 | 月の件数・人数 | 手取り |
|---|---|---|---|
| 入口の有料記事 | 980円 | 20件 | 約16,760円 |
| 実用の有料記事 | 1,480円 | 10件 | 約12,650円 |
| 本命「味つけ設計図」 | 2,980円 | 15件 | 約38,220円 |
| 有料マガジン | 3,980円 | 3件 | 約10,210円 |
| メンバーシップ(質問への回答+限定記事) | 月800円 | 40人 | 約27,360円 |
| 合計(振込手数料のあと) | | | 約104,900円 |

- メンバーシップは、購入者が50〜100人を超えてから始める【うと】。料理家のメンバーシップの相場は月580〜880円
- 必要なもの:有料記事と本命の積み上げ、マガジン、メンバーシップ、SNS の固定読者
- 時期の見立て:12か月以上(推測)
- 大事なこと:低単価の記事だけでは月30〜50万円で頭打ちになりやすい、という指摘がある【らっこ】。月10万円を超えたら、オンライン教室・個別の相談(顔を出さない形)など、上位の商品を検討する

## 計画を守るためのルール

- 毎週、数字を記録して、月の途中で「あと何件」を見る【ねこ太】
- 単価を下げて件数を追わない。500円以下で月10万円は235件以上が必要で、構造的にむずかしい【ひらかわ・かけち】
- 煽りの強い売り方で一時的に売上を上げない。長く売れる方を選ぶ【ひらかわ】
- アフィリエイト(はかり・温度計などの道具)は補助。計画の数字には入れていない
