# ⑤ 無料記事から有料記事につなげる導線設計

根拠:無料記事は「信頼づくり」ではなく「有料記事をより多くの人に読んでもらうため」に書く。潜在層(まだ原因に気づいていない人)に向けて書き、記事どうしをつなぐ【ぽにょ】。投稿 → プロフィール → 自己紹介記事 → 有料記事の一本道を、どこも切らさない【かけち】。有料記事は「有料」というだけで開かれにくい【シズマ】。

## 1. 全体の流れ

```
(note の中)                                  (SNS)
おすすめ・検索・旬の話題                       X・Threads の投稿(記事の一部を切り出す)
      │                                             │
      ▼                                             ▼
無料の連載記事(潜在層向け)  ◀──────────  プロフィール(誰に/何が手に入る/なぜ自分が)
「レシピどおりなのに味が違うのは、量で覚えているから」     │
      │  記事の最後:関連の無料回+有料記事への案内       │
      ▼                                             ▼
自己紹介記事(固定表示)「料理人がつまずいたこと → 理屈がわかった瞬間 → 今」
      │
      ▼
入口の有料記事(980円)「塩分%早見表」など ──▶ 本命(2,980円)「味つけ設計図」
      │                                         │
      ▼                                         ▼
有料記事の最後:次に読むとよい記事・関連の有料記事    章ごとの有料マガジン(まとめ)
                                                │
                                                ▼
                                   (常連さんができたら)メンバーシップ
```

## 2. 記事の中に入れる導線(テンプレートの変更案)

いまの記事の型(導入 → 今回のたねあかし → なぜそうなるのか → 台所でためしてみましょう → まとめ → 次回予告 → #味のたねあかし)はそのままに、最後の部分を次のように変える。

1. まとめ
2. **関連する回への案内**(1〜2本):「塩の量の決め方は第1回で」のように、前の回と次の回へのリンク
3. **有料記事への案内**(関係があるときだけ、1〜2文):「料理ごとの塩分の目安を一覧にした早見表を、こちらにまとめています」+リンク。押し売りの言い方にしない
4. 次回予告
5. #味のたねあかし(と、関連するハッシュタグ)

- 無料の連載の本文は2000字前後のまま。導線の文は本文の字数に含めるが、短くする
- 有料記事の最後にも「次に読むとよい無料回」「関連の有料記事」を置く(買った人を次へつなぐ)【ぽにょ】

## 3. 有料記事の無料部分の作り方

- 初見の人(口コミや検索で来た人)にも刺さるように書く。業界の言葉や自分語りを並べない【ひらかわ】
- 入れるもの:読者の悩みの言い当て/なぜ今まで解決しなかったか(原因)/この記事を読むと何ができるようになるか/目次/書き手の一言紹介(調理歴15年の料理人)/(ある場合)買った人の感想
- 有料部分の文字数は売上とほぼ関係がない(note 公式データ)。書きすぎず、1つのゴールにたどり着ける量にする【ひらかわ】

## 4. 自己紹介記事(固定表示にする)

- 構成:料理を始めたころ・修業中につまずいた味つけの話 → 理屈がわかった瞬間 → 今、家庭の料理人に伝えたいこと【かけち】
- すべて本人の実話で書く(作り話にしない決まり)。Claude は構成と質問を用意し、本人が音声入力で話した内容を整える
- 最後に、連載の読み方(第1章から)と、入口の有料記事への案内

## 5. マガジンの使い方

- 無料マガジン:章ごと(「第1章 塩」など)。連載を順番に読めるようにする
- 有料マガジン:入口の有料記事が2本以上になったら、まとめ価格で(合計より安く)【うと】
- 本命の有料記事が出たら、入口の記事と本命をつなぐマガジンにする【かけち】

## 6. note の機能の活用

- 質問箱(2026年5月〜):読者の質問を集め、無料回や有料記事のテーマにする。答えた内容を記事にする
- プロフィールに固定する記事:自己紹介記事、第1回、入口の有料記事
- ハッシュタグ:#味のたねあかし に加えて、旬の食材や悩みの言葉(例:#塩加減 #さつまいも)
- LINE 友だち追加ボタン(2026年1月〜):連絡手段を持つ場合の候補(運用の手間と相談して決める)

## 7. 導線が切れていないかの確かめ方

- 週に1回、数字で確かめる:無料記事のビュー → 有料記事のビュー → 購入数
- 切れている場所によって直す所を変える【ねこ太】
  - 見られていない → 集客(タイトル・SNS)を直す
  - 見られたが買われない → タイトル・無料部分を直す
  - 買った人の反応が薄い → 中身を直す
