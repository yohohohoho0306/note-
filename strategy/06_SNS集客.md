# ⑥ SNS を利用した集客戦略

## 1. 方針

- SNS は「フォロワーを増やす場」ではなく、「悩みの需要を確かめ、買ってくれそうな人とつながる場」【ねこ太・ひらかわ】
- 顔・店名は出さない。文字中心で続けられる形にする
- 投稿はゼロから考えず、連載の記事を切り出して作る(記事が投稿のネタ帳になる)【ぽにょ】。下書きは Claude、確認と投稿は本人
- インプレッションと売上は比例しない(100万インプレッションで500円の記事が2部だった例)【かけち】。数字は「保存・ブックマーク」と「note への移動」を重視する

## 2. どの SNS を使うか(分析者の提案)

| SNS | 使い方 | 理由 |
|---|---|---|
| Threads(主) | 毎日の投稿。料理の悩みと理屈の一言 | 文字中心で始めやすく、似た関心の人とつながりやすい【シズマ・らっこ】。家庭料理の話題になじむ |
| X(副・調査) | 需要の調査(検索)、記事の告知、Threads と同じ投稿の転用 | 検索で反応の多い投稿を絞り込める(min_faves)【ねこ太】。note との相性がよい【らっこ】 |
| Instagram(将来) | Canva で作った図解の投稿(カルーセル) | 料理は画像の媒体と相性がよい。ただし画像づくりの負担があるので、図解を Canva で量産できるようになってから |

- 最初から全部はやらない(全部やると中途半端になる)【在宅ワーク講座】

## 3. プロフィール(X・Threads 共通)

名前は note とそろえる(2026-10-31 の案。アカウントを作るのは本人):

- 表示名:たいしょう@現役料理人(note と同じ)
- ユーザー名:@taisyo_0726(note ID と同じ。X は15字まで、Threads は Instagram のユーザー名と同じになる)
- 自己紹介(note の自己紹介をもとに短くした案):「洋食・ビストロやカフェの厨房で15年、酒好きな料理人です(笑)お客さんによく聞かれる「なんでこれおいしいの?」を、家の台所で試せる形でお話しします。レシピどおりなのに味が決まらない人へ|note で連載『味のたねあかし』」+ note のリンク

3つを入れる:誰に/何が手に入るか/なぜ自分が言えるか【ねこ太】

- 例:「調理歴15年の料理人|レシピどおりなのに味が決まらない人へ、味つけの『理屈』を家庭の言葉で|note で連載『味のたねあかし』」
- 固定する投稿:連載の第1回か、自己紹介記事へのリンク

## 4. 投稿の種類と割合(1日2投稿の場合の例)

| 種類 | 中身 | 割合 | ねらい |
|---|---|---|---|
| 悩みの言い当て+理屈の一言 | 「煮物がしょっぱくなるのは、〜だからです」 | 4割 | 潜在層に気づいてもらう【ぽにょ】 |
| 数字・保存版のコツ | 「汁物の塩は重さの0.8%前後(確認済みの数値)」 | 3割 | 保存・ブックマークされる |
| 旬の話題 | 「今が旬の里芋、ぬめりは取る?残す?」 | 2割 | 季節の関心にのる |
| 記事の告知 | 新しい回の公開、有料記事の案内 | 1割 | note への移動 |

- 数値・安全に関わる投稿は、記事で本人が確かめた数値だけを使う
- 売る投稿は少なく。Threads では、売る投稿は20本に1本ほどでも売れる、という主張がある【ルパン15世。根拠は示されていない】。上の表の「記事の告知」1割は、有料記事の案内に限ればもっと少なくてよい
- 立ち位置:Threads では「少し先を行く同世代」、X では「教える先生」が受ける、という主張がある【ルパン15世】。たいしょうさんは料理人なので、Threads でも上から教えず、「家の台所で困ること」に寄りそう言い方にする
- 他の人の投稿への返信は、「素敵ですね」で終わらせず、具体的な一言(料理の理屈やコツ)を添える【ルパン15世】。返信は本人が行う
- 煽り・誇大な表現、個人攻撃はしない(炎上は避けられる)【らっこ】

## 5. 需要の調査のやり方(月1回+有料記事を作る前)

1. X で「味が決まらない」「しょっぱい 直し方」「煮物 味 しみない」「魚 臭い 焼き魚」などを検索し、min_faves で反応の多い投稿に絞る(料理は恋愛より反応が少ないので、300や100から試す)【ねこ太】
2. インプレッション・いいね・ブックマーク(最重要)を見る
3. 伸びた投稿の「なぜ伸びたか」(書き出し/悩みの言い当て方/すぐ使える例)を、Claude に投稿を貼って分析させ、自分でも確かめる【ねこ太】
4. 結果を research/ に記録し、有料記事のテーマと優先順位を決める

## 6. 数字の見方(週1回)

- 投稿ごと:インプレッション、保存・ブックマーク、プロフィールへの移動
- note:SNS から来た読者の数(わかる範囲で)、無料記事 → 有料記事への移動、購入数
- 何度出しても反応のない悩みは、その悩みの人が少ないと考えて選び直す【ねこ太】

## 7. 作業時間の目安

- Claude が記事から投稿案を作る:1記事につき5〜10本
- 本人の確認と投稿:1日10〜15分(予約投稿の道具を使えばまとめて)
- 需要の調査:月1回30分ほど
