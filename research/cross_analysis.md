## 2. 動画ごとに異なる主張・相反するノウハウ

### 価格
- 高単価派:最低5,000円、できれば1万円以上【ひらかわ】
- 中単価:3,980円【ねこ太の実例】、4,980円・3,980円【ぽにょの紹介する事例】
- 中単価(最初の1本):1,980〜2,980円【うと】
- 相場に合わせて低めから:note の検索を「有料の記事」に絞って同じテーマの相場を見て、相場に合わせて出し、売れたら値上げ。片付け・睡眠などは500〜1,000円【うと(AI 丸投げの動画)】
- 付加価値で相場を超える:相場が上げにくいジャンルは、テンプレート・チェックリスト・限定動画・質問フォームを足す【ひらかわ】
- 階段派:500円(入口)→ 2,980円(本命)→ 4,480円(まとめ)【かけち】、低単価で始めて月30〜50万円を超えたら高単価の商品(コンサルなど)をアップセル【らっこ】
- note 公式データ:売れている実用ノウハウ系の平均価格は1,842円(2026-01)
- 読み方:価格は「ジャンルの悩みの深さ」「ジャンルの相場」「読者との信頼の深さ」で変わる。どの投稿者も、安すぎると必要な人数が多すぎる点では一致している。料理は生活系で相場が低めになりやすいので、相場を調べたうえで、付加価値(印刷できる表など)で上げる方向が合う

### SNS は必要か
- 不要派:SNS なしで note の中だけで売れる【在宅ワーク講座】、SNS なしでも月2〜3万円まで(それ以上は SNS が必要)【ぽにょ】
- 必要派:X で悩みの需要を確かめ、買ってくれそうな人とつながる【ねこ太】、X の投稿 → リスト → 記事の一本道【かけち】、X が中心で Threads は補助【らっこ】
- 中間:フォロワー数はいらないが、深く刺さる少数とはつながる【ひらかわ】
- 失敗例:新しいアカウントで SNS の母数がなく、30日でほぼ売れなかった【シズマ】
- 読み方:「SNS なしで月2〜3万円」【ぽにょ】までは note の中だけでも届きうるが、それ以上や、早く最初の売上を作るには SNS(特に X)で需要を確かめ、つながる方法が有力

### メンバーシップ(月額)は始めるべきか
- 慎重:フォロワーがいない状態から始めるのは「地獄の入り口」。続ける理由を毎月作る・解約がかんたん・集客し続ける、の3つで疲弊する。向くのはフォロワー万単位か購入者100人以上で実績のある人。やるならプラン1つ・約束は少なめ・撤退ライン(例:6か月で50人)を先に【うと】
- 公式データ:メンバーシップの売上は前年比+81%、売上が出たクリエイター数は約2倍(2025年11月)。料理家のメンバーシップも公式が例に挙げている
- 読み方:「伸びている市場」と「初心者が最初に選ぶと疲弊しやすい売り方」は両立する。順番の問題で、有料記事で常連さんができてからが安全

### ローンチ(短期間に集中して売る)
- 推奨:教育(信頼・目的・問題点・手段・投資・行動)と告知をしてから販売、売れたら報告【かけち】、期間・人数の限定(希少性)を入れないと売上がゆるむ【らっこ】
- 慎重:派手なローンチは初月だけ伸びて落ちる。興味のある人に軽く告知して静かに出す方が長く売れる【ひらかわ】
- 読み方:短期の売上と長期の信頼のどちらを優先するかの違い。継続的な連載では、煽りに見えない範囲の「限定」と「告知」にとどめるのが安全

### AI にどこまで任せるか
- 区切って書かせる:ChatGPT でテーマと全体像を壁打ち → Claude で章ごとに500〜1,000字ずつ → 人が音読して直し、体験談を足す【ニートパパ】
- 指示書で丸ごと書かせる:Claude Code に「指示書」(読者・トーン・構成・字数・禁止語・最後の案内)を読ませて1本(約2,500字)を書かせ、「別の編集者の視点」で見直させ、事実は人が一次情報で確かめる。note には下書きで入れ、公開は人【SHIFT AI】
- 丸投げへの批判:AI に丸投げした記事は「電子ゴミ」【うと】、AI の文章のままでは売れない【ぽにょ】
- 聞き手にする:AI は書き手ではなくインタビュアー。本人が音声で話し、AI が場面・思い込み・原因を抜き出し、チェックリストにまとめる。経験のない分野の0から1、体験談の捏造、数字を作ること、最後の判断は任せない【ひらかわ】
- 土台を作らせて直す:有料部分の目次 → 1章ずつ約1,000字 → 無料部分 → 全体をつなぐ(字数を保つ指示)→ 最後に自分の経験を足す。タイトルは「AI 丸投げ・15分」だが、中身は何度も直す手順【うと(AI 丸投げの動画)】
- 読み方:5者とも「事実の確認と最後の判断は人」で一致している。違うのは、AI に任せる単位(章ごとか1本丸ごとか)、書き方のルールを毎回伝えるかファイルにしておくか、そして土台に本人の経験があるか

### 経験のない分野を AI で書いてよいか
- よい:AI にテーマ案を出させ、経験のない分野(転職の例)でも有料記事を作れる。最後に自分の言葉と体験を足す【ニートパパ】
- だめ:経験のない分野の0から1を AI にやらせた記事は、買う理由がない・誰でも作れて値下げ合戦になる・読者の質問に答えられず続かない、の3つで中長期に詰む【ひらかわ】
- 書き手のキャラクター:「完全に自分でなくてもよい、漫画のキャラを参考に」【うと(AI 丸投げの動画)】と、「体験談を作らない」【ひらかわ】は相反する
- 読み方:ニートパパの例も「最後に体験談を足す」前提なので、体験のない人には実は使えない。長く売るなら、ひらかわさんの「経験の上で AI」の方が筋が通る(ただし「詰む」は将来の予測で、データではない)

### note は「イージー」か「ハード」か
- ハード:新しいアカウント・需要の確かめなしで30日 → ほぼ売れない【シズマ】
- イージー(正しくやれば):売れない検証は、需要のないジャンルと手抜きの記事のせい【ぽにょ】
- 読み方:両者の事実認識(需要のないジャンル・準備不足)は一致している。違うのは「note 自体の難しさ」か「やり方の問題」かという解釈

## 3. 信頼性が高そうな手法(根拠と再現性から)

- 「単価×人数」で目標を分解する(計算で確かめられる)
- 書く前に需要を確かめる(X の検索で反応の多い悩みを探す【ねこ太】、note の中で売れている記事を自分の目で見る【ぽにょ】、note の検索を「有料の記事」に絞って同じテーマの記事があるかを見る【ニートパパ】)
- 書き方のルール(読者・トーン・構成・禁止語)をファイルにして毎回読ませる【SHIFT AI】。人によって品質がぶれにくい
- 有料部分を先に書き、そのあと無料部分を書く【うと】。章ごとに区切って書かせる【うと・ニートパパ】
- テーマは「名詞で終わる」形にし、気持ちの話ではなく困りごとを体系化する【うと】
- 有料記事の中身を、決まった切り口(考え方・初心者向け・細かいコツ・数値の基準・時短・やってはいけない例・実例)で点検する【ニートパパ】
- 経験を商品にする5つのステップ(一番痛かった場面 → 当時の思い込み → 構造での原因 → 抜け出した判断(何をやめたか)→ チェックリストなどの道具)【ひらかわ】
- 相場が上げにくいジャンルは、中身を水増しせず、テンプレート・チェックリスト・限定動画・質問フォームなどの手助けを足す【ひらかわ】
- 売れない原因を「見られていない/買われない/買った人の反応が薄い」に分けて1つずつ直す【ねこ太】
- 無料記事(潜在層向け)→ 有料記事(顕在層向け)の導線【ぽにょ】
- 自己紹介記事を「ダメだった過去 → 出会い → 今」で、具体的に書く【かけち】

## 4. 再現性が低そうな手法・注意が必要な主張

- 月数百万〜数千万円の売上や「1記事で4億円」「毎月3,000万〜5,000万円を自動で」「累計25億円」などの実績(申告のみ。成功者だけが語っている。無料セミナーや LINE 登録への誘導とセットのことが多い)
- 「同じテーマの有料記事が1本もなければ需要がない」【ニートパパ】(note の外の需要を見落とす。逆に数千件あれば埋もれる心配もある)
- 「AI なら30分〜数日で有料記事が完成」【ニートパパ】、「AI 丸投げで15分」【うと】(どちらも中身の正しさを確かめる時間が入っていない。うとさんの動画は、中身では何度も直している)
- 「スキの数の1.5〜2倍が実際の販売数」【うと】(「と言われている」という伝聞で根拠なし。本人もスキは買えると注意)
- 「100万インプレッションを出す」「大手に引用されてバズる」(運の要素が大きい。かけち自身も、100万インプレッションで500円の記事が2部しか売れなかったと話している)
- 「SNS なしで月100万円」(在宅ワーク講座。根拠の数字の出典が示されていない)
- 動画内で紹介された「note の利用者8,600万人」「流入の42%が検索」などの数字(公式の出典を確かめられなかった)

## 5. 初心者が優先して取り組むべきこと(共通項から)

1. 需要のある悩みを1つ選ぶ(自分の経験 × お金を払ってでも解決したい悩み × その悩みの人が本当にいる)
2. 目標を単価×人数に分ける
3. 有料記事を1本作る(変化の約束 → 共感 → 解決までの道のり → 最初の一歩、書きすぎない)
4. 無料記事・自己紹介記事で、有料記事への導線を作る
5. 出して、反応を見て、原因を分けて直す
