## 1. 主張・結論

- note で楽天アフィリエイトは使える。ブログ(WordPress)を作らなくても、note の記事に楽天の商品のリンクを入れられる[02:43〜03:09]
- 大事なのはリンクを並べることではなく、「誰に・どの商品を・どう自分の体験として伝えるか」[01:02〜01:34]

## 2. note で収益が発生する仕組み

- note の記事で楽天市場の商品を紹介し、読者がリンクから楽天市場に行って対象の商品を買うと、紹介者に報酬が入る。クリックされただけでは報酬は出ない[03:56〜04:41]
- 本人は、楽天アフィリエイトのやり方をまとめた有料記事も note で売っている(概要欄)

## 3. 具体的な収益化手法

- 始める5つのステップ[06:01〜11:28]
  1. note のアカウントを作る
  2. 楽天 ID を用意し、楽天アフィリエイトにログインする
  3. 楽天アフィリエイトに note を「サイト登録」する(サイト名に note の名前、URL に note のプロフィールページ。最初に1回だけ)
  4. 紹介したい商品を楽天アフィリエイトの画面で探す
  5. 「商品リンクを作成」→ SNS 用のリンク → note のアイコンでリンクを取り、記事に貼る。リンクのまわりに自分の体験を書く

## 4. 売れる記事・テーマの選び方

- 最初の商品は、自分の楽天市場の購入履歴から選ぶ。そのために新しく買わなくてよい(子ども用品、家事が楽になるもの、日用品、台所用品など)[04:56〜05:44]
- 使ったことのない商品を商品ページの情報だけで紹介すると、ほかの記事と似た中身になる[05:14〜05:44]

## 10. 実際の作業手順

- 3の5つのステップのあと、公開前のチェック[15:11〜16:45]
  - note のサイト登録は済んでいるか
  - 商品の説明と感想を自分の言葉で書いているか(他人のレビューや商品ページの文をそのまま使っていないか)
  - 楽天の商品画像を勝手にスクリーンショットしていないか
  - 「保証」「誰でも」「絶対」などの言いすぎがないか
  - 無料で商品をもらった場合などに、広告・PR の表示が要るか
  - リンクを押して、正しい商品ページに行くか
  - 他の人のコメント欄など、禁止の場所にリンクを貼っていないか
  - 同じ悩みの読者の役に立つ中身か

## 11. 成功のポイント(投稿者の主張)

- 売り込むのではなく、以前の自分と同じ悩みの人に、自分の体験を伝えるつもりで書く[12:03]
- 完璧な記事より、まず自分の体験を正直に書いた1本[16:45、17:16]

## 12. 失敗しやすい点・注意点(投稿者の主張)

- 知っておく7つのルール[12:28〜15:11]
  1. note をサイト登録する
  2. 自分のリンクから自分で買わない(同居の家族・友人と示し合わせた購入も禁止)
  3. 楽天市場のほかの人のレビューをコピーしない
  4. 楽天市場の商品画像を勝手にスクリーンショットして載せない。使ってよい画像でも、文字を重ねるなどの加工が禁止の場合がある
  5. 言いすぎ・根拠のない断言をしない
  6. 必要なときは広告・PR であることをはっきり示す。迷うなら付けておく方が安心
  7. 他の人の note のコメント欄に楽天のリンクを貼らない
- 以前の情報では「note では楽天アフィリエイトが禁止」とされていたことがあるが、今の公式ガイドラインでは使える、と説明[02:43〜03:09]
