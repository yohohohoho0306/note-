## 1. 主張・結論

- note は、利用者が多いのにまだ参入者が少ない「穴場」。顔や名前を出さずに、文章だけで、メールアドレス1つで始められる[02:41〜07:03]

## 2. note で収益が発生する仕組み

- note を選ぶ理由:利用者数が最も多い、一度買った人は次からワンクリックで買える(Amazon と同じ)、Brain や Tips より「クリーンなイメージ」で購入率が高い[02:41〜03:48]
- 低単価の有料記事は月30〜50万円で頭打ちになりやすい。そこを超えたら、記事を買った人により高い商品(コンサルなど)を提案する「アップセル」で月100万円ほどまで伸ばす[27:02〜28:38]

## 3. 具体的な収益化手法

- X で集客して note の低単価の記事を売る(らっこさんのスクールで最も多い、最も再現性のある形)[27:02]
- 希少性の原理:販売日数や販売数をあえて少なくする(例:3日間限定の割引、100人限定)。入れないと売上がゆるむ[21:50〜23:53]

## 4. 売れる記事・テーマの選び方

- まず自分の経験を棚卸しする(ChatGPT と5〜10分壁打ちして人生を振り返るとよい)[14:00〜16:07]
- 経験も知識もない人が2026年に始めるなら:恋愛、占い、スピリチュアル、筋トレ・ダイエット、美容・健康。どれも悩みが深く、誰もが一度は悩む。得意である必要はないが、嫌悪感がなく、興味を持って学べるものを選ぶ[14:30〜15:37]
- 聞き手のうとさんは、自分が今やるなら「アラフォーの美容」と回答[15:37]

- 低単価の記事で始め、月30〜50万円を超えたら高単価の商品と組み合わせる[27:37〜28:07]

- アカウントの設計(コンセプト、アイコンなど)と、伸び始めるまで(最初の3か月ほど)は自分でやる。軌道に乗ったら AI や外注で仕組み化する[17:37〜18:14]

## 10. 実際の作業手順

1. 自分の経験を棚卸しし、悩みの深いジャンルの中から興味の持てるものを選ぶ
2. アカウントを設計し、最初の3か月ほどは自分で運用する
3. X で集客し、低単価の有料記事を売る(希少性を入れる)
4. 軌道に乗ったら、投稿を AI・外注で仕組み化する
5. 月30〜50万円を超えたら、アップセル(高単価の商品)を組み合わせる
