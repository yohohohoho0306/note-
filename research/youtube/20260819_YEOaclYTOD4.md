# 【初心者これ一択】note作成せずに「note」で稼ぐ方法【AIアフィリエイト】

- チャンネル:ルパン15世【在宅で稼ぐ顔出しなしアフィリエイト】
- 公開日:2026-08-19/長さ:約27分/再生回数:25,391(2026-10-30 時点)
- シリーズ:単独。Threads のアフィリエイトの動画が別にある(概要欄)
- 文字起こし:YouTube 自動字幕。訳したような不自然な日本語で、誤りが多い(「月1000万ドル」「脳とヒント(Brain と Tips のこと)」「500円札」など)。金額の単位などは文脈から円と読みかえた。概要欄も記録json に保存
- 投稿者の申告:受講生500人以上のアフィリエイト講座を運営。毎月1,000万円以上を安定して稼ぐ。累計8億3,000万円[00:01、01:02、24:49]
- 注意:タイトルは「note で稼ぐ」だが、動画で勧めているのは note ではなく、別の販売サイト(Brain・Tips)の有料コンテンツを SNS で紹介するアフィリエイト。note は使わない

## 1. 主張・結論

- 初心者が note を書き始めても稼げない。初心者のうちは、有料記事を売ることは「絶対に避けるべき」[00:01、05:32]
- 初心者がスキルも実績もなく稼ぐなら、「コンテンツアフィリエイト」(Brain・Tips の商品を SNS で紹介し、売れたら紹介料を受け取る)が唯一の選択肢[08:35〜09:05]

## 2. note で収益が発生する仕組み

- note での収益の話はない。収益は、Brain・Tips のアフィリエイトの紹介料(1件で数千円〜数万円)[14:11〜14:41]

## 3. 具体的な収益化手法

- 紹介する商品を3つの価格帯でそろえる:入口3,000円前後、中間1万〜2万円、主力3万〜5万円[15:12]
- 月30万円の内訳(本人の試算):入口の紹介料約1,500円×30件=4.5万円、中間5,000〜1万円×10件=5万〜10万円、主力1.5万〜2.5万円×8件=12万〜20万円[15:42〜16:12]
- 商品はランキング上位3位ではなく、5〜15位の「中堅のヒット」を選ぶ(紹介する人が少なく、販売者が投稿を広めてくれやすい)[16:12〜16:42]
- 主に使う SNS で売れている人を3〜5人選び、その人たちと同じ商品を紹介する[16:42〜17:13]
- 7日で始める:1日目に商品を1つ買う → 2日目に Threads のアカウントとプロフィール → 3〜5日目に共感の投稿でフォロワーを作る → 6日目にレビュー記事を書く → 7日目に公開してリンクを置く[22:45〜23:15]

## 4. 売れる記事・テーマの選び方

- Brain・Tips の性質上、ビジネス・スキルアップ系がよい。今は AI 活用と SNS 運用が人気[16:12]
- 「月100万円稼ぐ方法」のような商品は、自分が実際に稼ぐまでレビューを書けない。AI・業務・時短・ツールの商品なら、翌日には結果(作業時間が3時間 → 20分、など)を書ける[18:13〜19:14]

## 5. 有料記事の価格設定

- 有料記事の話はなし。紹介する商品の価格帯は3の通り
- 低価格(500円・1,000円・3,000円)の商品がよく売れる時代になった、と説明[03:32〜04:02]

## 6. 読者を集める方法

- Threads を主に、X と両方に投稿する[16:42]
- 投稿の配分:「え、本当に?」と思う気づきの投稿30%、「すごくわかる」と思う共感の投稿50%、すぐ試せる小さなコツ15%、アフィリエイトの投稿5%(20本に1本)[20:45〜21:45]
- 売り込まず、「困ったときにこの人の投稿を思い出す」状態を作る[20:45]
- 他の人への返信は、「素敵ですね」ではなく、自分の経験を入れた深い返信を1日10件ほど[21:45〜22:15]

## 7. SEO・SNS の活用

- note は SEO と SNS の両方に強い、という一般論のみ[03:02〜03:32]
- X では上から教える「先生」の立ち位置が受け、Threads では「少しだけ先を行く同世代」の立ち位置が受ける。Threads で伸びている人の90%は「私もつい最近同じことで困っていた」という立場[19:14〜19:44]

## 8. リピーター・ファンを増やす方法

- 動画では説明なし(SNS で「思い出してもらう」話のみ)

## 9. AI の活用

- レビューの下書きを AI に書かせてよい。ただし、自分のふだんの投稿を渡して文体・改行をまねさせ、最後に自分で読み直して「心からの一言」を足す[19:14]
- Threads のプロフィール案を AI に3つ出させ、すぐに決めて始める[19:44〜20:15]

## 10. 実際の作業手順

- 3の「7日で始める」の通り

## 11. 成功のポイント(投稿者の主張)

- 紹介する人の実績ではなく、商品を作った人の実績と信頼を借りられる[10:37〜12:09]
- 返品・苦情・サポートは販売者が行うので、気持ちが楽[12:39〜13:10]
- 完璧な準備を待たず、7日で始める[22:15]

## 12. 失敗しやすい点・注意点(投稿者の主張)

- 初心者が note で失敗する3つの理由:売れる商品が作れない(AI の文章を直す力がない)、集客ができない、やる気が続かない[04:32〜08:05]
- 高い商品ばかり勧めると、信頼ができる前に離れられる。安い商品だけでは件数が足りない[15:12]

## 分析者のメモ(動画の内容ではなく、こちらの評価)

- 根拠の強さ:実績はすべて申告で、概要欄は「総額110万円相当の特典」など、誇大な広告の特徴が多い。字幕の質も低く、細かい数字は信頼できない
- タイトルの「note で稼ぐ」は中身と合っていない。note の収益化の参考にはならない
- ほかの動画との違い:「初心者は有料記事を売るのは絶対に避ける」は、ほかのほぼ全員(有料記事を1本作って直す)と正反対。また、「自分の知識・経験はまったく要らない」「商品を作った人の実績を借りる」は、ひらかわさん・ニートパパの「実体験・一次情報が評価される」流れと逆
- 注意:使っていない商品を紹介したり、他人の実績を自分の投稿の「武器」にしたりするやり方は、読者の信頼を損ねるおそれがある。紹介料をもらう投稿では、広告であることの表示も必要になる(どう表示するかは各サービスの決まりと法令で確かめる)
- それでも参考になる点(どれも投稿者の主張で、根拠は示されていない):
  - Threads の投稿の配分(売る投稿は20本に1本)と、「少し先を行く同世代」の立ち位置。⑥ の SNS 戦略の「売り込まない」方針と一致する
  - 深い返信を1日10件
  - 価格の3段階(入口 → 中間 → 主力)は、かけちさんの「入口 → 本命 → まとめ」と同じ形
- 味のたねあかしとの関係:Brain・Tips の情報商材のアフィリエイトは、料理の連載とは合わないので取り入れない。アフィリエイトを使うなら、本人が実際に使っている道具(はかり・温度計など)の紹介に限る(次の動画で、note の中の楽天アフィリエイトを確かめる)
