## 1. 主張・結論

- 結論:「note はイージーモードではなくスーパーハードモードだった」[21:12]
- 失敗の原因として本人が気づいたこと:ゴールの設計ミス(「ツールを作れるか」をテーマにしたため、完成したら目的を見失った)、自分が欲しいものを基準にテーマを選んだ、「30日チャレンジ」のタグを後から付け足した[10:13〜10:45]

## 2. note で収益が発生する仕組み

- 有料記事の販売を試みた。売上の具体的な数字は動画で明言されていない(閲覧数がごく少なく、本人は「厳しかった」と述べている)

## 3. 具体的な収益化手法(試したこと)

- 当初の計画:作業の過程を毎日記事にし、1週間分のまとめを数百円、1か月分のまとめを1,000円前後で売る[02:31〜03:02]
- 中間地点(15日目)に100円の有料記事 → 4日で閲覧2。無料に変えたら1日で閲覧9 →「有料というだけで開かれていない」可能性が高いと判断[11:46〜14:22]
- 最後に方針を変え、「30日の失敗から見つけた穴場ジャンル2選」という有料記事(全体約1.4万字、有料部分約1.1万字)を500円で出し、2日間のタイムセールで300円、1週間で削除すると予告。前日に「プレ記事」(なぜこの記事を出すのかの経緯)を出した[15:55〜18:57]

## 4. 売れる記事・テーマの選び方

- 「一次情報が最もおすすめ表示の優先順位が高い(note の CXO が公式に発言)」という情報をもとに、「何かに取り組んで、その過程を発信する」形を選んだ[00:30〜01:01]
- 選んだテーマ:AI エージェントでツールを作る過程(対象は40〜50代の PC に詳しくない人)。ニッチすぎて需要がなかった、と途中で判断[07:37]
- 他の人の記事を見て気づいたこと:日記のような「副業30日やってみた」記事が、内容が薄くても伸びていた[05:04〜06:35]

## 5. 有料記事の価格設定

- 100円は「価値が安く見えて売れない」という話も見たが、価値が見合わないとして100円にした[12:17]
- 最後の記事は500円 → タイムセール300円。「カモにする気はないので500円の価値を持たせる」[16:26]
- note のタイムセールは30分刻みでしか設定できず、予定より30分遅れた[19:28〜19:58]

## 6. 読者を集める方法

- 記事を出すたびに X と Threads に URL を投稿。Buffer で X と Threads に同時投稿[06:05]
- 記事の最後に翌日の記事の URL を貼り、回遊させる[06:05]
- 最後の2日間は、Threads と note で note 初心者をフォローして積極的につながり、「あなたの有料記事を読ませて」という投稿に自分の記事を貼った[19:58〜20:31]

## 7. SEO・SNS の活用

- X のアカウントは作って1時間で凍結(誤判定で後に解除)[02:01]。15日時点で X のフォロワー0、Threads 10人[12:49〜13:20]
- Threads は、note 初心者を何人かフォローすると似たアカウントが次々おすすめに出て、つながりやすい[19:58]

## 8. リピーター・ファンを増やす方法

- 「ファンがついていないのは明らか」で、まとめ記事の有料化を断念[08:38]。方向がぶれたため、ファンづくりができなかった

## 9. AI の活用

- 開発に Codex(月額約3,000円。今回は初月無料)を使った[21:12]
- リサーチに AI を使うが、AI が根拠つきで持ってきたデータも元のソースまでたどって確かめ、ダメなものを外した[16:56、19:28]

## 10. 実際の作業手順(行ったこと)

1. ジャンルを決め、note・X・Threads のアカウントを新しく作る
2. 毎日、作業して記事を書く(初日は記事に約9時間かかった)
3. 他の人の記事を見て、タイトルなどを直す
4. 中間地点で有料記事 → 開かれないので無料に変えて原因を切り分ける
5. 最後にテーマを変え、プレ記事 → 有料記事(タイムセール・削除予告つき)を出す

## 11. 成功のポイント(本人の反省からの学び)

- 最初にゴール(何を、誰に、いくらで売るか)を設計しておく
- 自分が欲しいものではなく、読者の需要を基準にテーマを選ぶ
- 有料記事は「有料」というだけで開かれにくいので、どう売るかを最初から見据えて動く[14:22]

## 12. 失敗しやすい点・注意点(本人の体験)

- 記事作成に慣れるまで想像以上に時間がかかる(初日9時間、スクショの加工が大変 → 加工ソフトを入れた)[03:02]
- ニッチすぎるテーマは需要がない。途中でテーマがずれる
- 新しいアカウントだけでは母数(閲覧数)が圧倒的に足りない[21:12]

## 分析者のメモ(動画の内容ではなく、こちらの評価)

- 根拠の強さ:画面で数字を示した検証で、ほかの「成功談」の動画より事実としての信頼度は高い。ただし1人・1回の検証
- 再現性:「新しいアカウントで、需要を確かめずにテーマを選び、途中で方向がぶれると、30日では売れない」という失敗の再現性は高そう
- 成功談の動画への反証として重要:ねこ太さん(20261028_2fLzzC4MUfI)は「販売の1か月前から X で需要を確かめ、つながっておく」。シズマさんはそれをせずに始め、母数が足りなかった。両者は矛盾せず、準備の差が結果に出たと読める
- 「有料記事は開かれにくい」という観察は、無料記事から有料記事への導線の大切さを示す
- 味のたねあかしへの使いどころ:
  - 最初から「無料の連載で読者を集め、何を、いくらで売るか」を設計しておく(ゴールの設計)
  - 記事作成の時間は想像以上にかかる。本人の添削時間を含めて、無理のない投稿ペースを決める
  - 有料記事を出す前に、無料記事で「この人の記事は役に立つ」と思ってもらう母数(閲覧・フォロー)を作る
