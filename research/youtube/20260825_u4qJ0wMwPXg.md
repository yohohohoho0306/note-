## 1. 主張・結論

- SNS で外から人を連れてくる集客は「もう古い」。note は利用者が増えていて、記事がおすすめ表示される仕組みもあるので、お客さんは note の中にいる[04:35〜06:38]
- SNS なしでも、①有料記事を1本作る ②有料記事に人を呼ぶ無料記事を書く ③記事どうしをつなぐ、で月2〜3万円は狙える[23:30]
- ただし SNS なしでは月2〜3万円が限界。土台ができたら SNS を始めるべき[24:33〜25:34]

## 2. note で収益が発生する仕組み

- note の中のおすすめ表示や回遊で読まれた無料記事から、有料記事へ誘導して売る
- 1人の読者に記事を次々と読んでもらい、複数買ってもらうことで客単価を上げる[21:30〜22:00]

## 3. 具体的な収益化手法

- ステップ1:まず有料記事を1本作る(売り場を先に作る)。読者が今すぐ解決したい、緊急性の高い悩みに刺さるテーマ[07:40〜09:10]
- ステップ2:有料記事に人を呼ぶ無料記事を書く。無料記事の目的は「信頼やファンづくり」ではなく、「有料記事をより多くの人に読んでもらうこと」[12:46〜13:46]
- ステップ3:「スパイダーマーケティング」(本人の命名):無料記事の途中や最後で有料記事へのリンクを自然に貼る。有料記事の最後にも「こういう記事も書いています」と別の記事につなぐ[19:58〜21:30]

## 4. 売れる記事・テーマの選び方

- 「自分が儲かるには」ではなく、「お客さんにどんな悩みがあり、どうすれば解決できるか」から考える[09:10〜10:43]
- 身の回りの人の困りごと(家族・同僚の悩み)をテーマにしてよい。AI に、ジャンル別に「お客さんが悩みそうな点」を一気に出してもらうのもよい[10:43〜11:44]
- 無料記事は「ターゲットをあえてずらす」:有料記事を欲しがる「悩みを自覚している人(顕在層)」は少ない。「まだ原因に気づいていない人(潜在層)」に向けて無料記事を書き、悩みに気づいてもらう[14:16〜18:24]
  - 例:有料記事「夜なかなか寝つけない人が、お金をかけずにぐっすり眠れる方法」→ 無料記事「日中の疲れ・だるさ・ネガティブ思考、実は全部夜のある事が原因かも」
  - 「人は、自分の悩みに自分ごととして気づいた瞬間に、解決したいと思い、財布のひもがゆるむ」[18:24]

## 10. 実際の作業手順

1. 緊急性の高い悩みに刺さる有料記事を1本作る
2. 潜在層に向けた無料記事を書き、有料記事へ誘導する
3. 記事どうしをリンクでつなぐ(無料 → 有料、有料 → ほかの記事)
4. 月2〜3万円の土台ができたら、無料記事をもとに SNS 発信を始める

## 11. 成功のポイント(投稿者の主張)

## 12. 失敗しやすい点・注意点(投稿者の主張)

- 顕在層だけを狙うと、母数が少なすぎる
