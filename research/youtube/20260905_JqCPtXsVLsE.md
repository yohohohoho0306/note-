## 1. 主張・結論

- 月100万円に届くかは、才能やセンスではなく「順番」を知っているかどうか[00:00]
- モデルは「1記事 × 高単価 × 副産物」。記事を量産せず1本に絞り、高い値段にし、売って終わりにせず、記事をきっかけに生まれる別の売上を育てる[07:33〜08:41]
- 売上は「読者を成功させて初めて受け取れる、前借りのお金」。指標は自分の売上ではなく、読者が成功したか[19:10〜20:25、24:19]

## 2. note で収益が発生する仕組み

- 月の売上=単価 × 販売数(+副産物)。1万円×100本、5万円×20本、10万円×10本はどれも100万円。1,000円なら1,000本、500円なら2,000本が必要[02:52〜05:08]
- note は「ゴール」ではなく「入口の商品」。その先に副産物がある[28:25〜30:38]
- 副産物:本人の場合は、高額のスクールや講座ではなく、記事を読んで事業を始めた人が必要になるツール・倉庫業者・デザイン業者などの紹介(利用量に応じた紹介料)。読者が成功するほど、こちらの売上も増える[75:28〜78:35]

## 3. 具体的な収益化手法

- 9割の人が月100万円の手前で止まる3つの道[12:17〜19:23]
  1. 数百〜数千円の記事を量産する(書き続けないと売上が止まる)
  2. メンバーシップを主にする(「週刊誌型」で、月5〜10本の更新が続き、やめると減る。本人は収益目的なら絶対にやらない)
  3. フォロワーを増やそうと SNS に張りつく(SNS は知ってもらう場所で、売る場所ではない)
- 有料記事は「参考書型」:1冊よいものを作れば、何年も売れ続ける[16:20]
- ステップ0(土台):自分が何者か(誰のどんな悩みをどう解決する人か)、読者の成功を第1の指標に、3年後にいくら届いているかという長い物差し[21:20〜28:06]
- ステップ1(何を売るか):ノウハウではなく「変化」(A の状態から B の状態へ)を売る。テーマは「普遍性(5年後も価値が変わらない)× 需要(お金を払ってでも解決したい)× 自分の経験」の重なり。ターゲットは「悩みは深く、間口は広く」(属性を絞りすぎない)[31:08〜35:42]
- ステップ2(作り方):読者が出会う順番(タイトル → 見出し画像 → 無料部分 → 有料部分)で組む[36:44〜47:00]
  - タイトル:読む前と後で自分がどう変わるかが想像でき、具体的な数値や事例がある。煽らない。中身より期待値を少し下げるくらいでよい
  - 見出し画像:スクロールする指を止める。凝った絵より、悩みや得られる変化を短い言葉で。目がちかちかする派手な画像は、うさんくさく見え、判断力の落ちた人を呼ぶ
  - 無料部分:ここで買うかがほぼ決まる。共感 → なぜ自分が語れるか → 読むとどう変われるか → 核心は有料部分で。最初の数行(10秒)に一番力を入れる
  - 有料部分:情報を並べず、全体像 → 段階に分けた道のり → つまずく所を先回り → 実例 → 行動を促す、で読者をゴールまで連れていく。途中に小さな作業(ワーク)を入れると最後まで読まれる
  - note は装飾が少ないので、見出しと余白(適度な改行)で読みやすさに差がつく
- ステップ3(価格):3の「価格設定」を参照
- ステップ4(集客と導線):6・7を参照
- ステップ5(副産物と資産化):2・8を参照

## 4. 売れる記事・テーマの選び方

- 本人の失敗:最初の2年は「市場が大きいから」と健康・資産運用を選び、何者でもない人の健康日記になっていた。本業の経験に絞ってから変わった[22:57〜24:29]
- すごい肩書きは要らない。少し前の自分が悩んでいたことを今の自分が解決できていれば、少し前の自分がお客さん[24:29]
- 自分が書きたいことと、人がお金を払いたいことは別。インフルエンサーでなければ、自分が言いたいこと自体に需要があることはまずない[32:40〜33:10]

## 5. 有料記事の価格設定

- 安売りしない理由:価格は品質の合図になる/安いと本気でない人まで集まる/入口でまとまった収益を取ると、副産物に頼りすぎずに済む[48:31〜51:04]
- 本人の価格:製造販売の記事も、このアカウントの有料記事も5万円以上。製造販売の記事は最初1万9,800円で約2年売り、中身を足して5万円に上げた[51:04、58:12〜58:42]
- 「値段を先に決める(プライスファースト)」:書いたあとに値段をつけると安くなる。先に1万円と決めると、1万円以上の価値を出せているかの基準が上がる[52:34〜54:06]
- 高い値段の理由の見せ方:払う額より返ってくる額(収入・身につくスキル)が大きいことを、筋道立てて示す。コンサルやスクールの料金と比べる。返ってくるものについて嘘はつかない[55:38〜56:39]
- 高単価と低単価の使い分け:大きな変化を届ける本命は高く、気軽に触れてもらう入口は安く(本人は月500円のメンバーシップを接点に使う)。ただし大半の人は「高単価の1本に集中」でよい[56:39〜58:12]
- 値上げ:実績・口コミがたまったときか、中身を足したとき。先に告知し、すでに買った人には追加分をそのまま届ける。補う内容やアップデートを別の商品として売らない[58:42〜60:44]

## 6. 読者を集める方法

- 勝負を分けるのは中身より「届け方」。いい記事も、見つけてもらえなければ売上はゼロ[61:14〜62:47]
- SNS(Threads・X・Instagram・YouTube)は「知ってもらう」担当、note は「売る」担当。人は「知る → 信頼する → 買う」の順で動く。SNS で売り込まず、有益な発信 → プロフィール・固定投稿 → note・公式 LINE へ[64:19〜66:51]
- 公式 LINE やメール(メルマガ)で、見込みのお客さんと直接つながる。SNS は届かなくなることがある[66:51〜68:22]
- 本人は Threads を0から始めて5か月かからずにフォロワー約1万人。売り込みはしていない[65:51]
- 製造販売の記事を買った人の6割以上が、本人を知って半年以内の人。だから、初めて見た人にも伝わる作りにする[37:46]

## 7. SEO・SNS の活用

- note は検索に強い。悩みを持つ人が実際に打ち込む言葉を、タイトルと中身に入れる。過去の記事が24時間働く営業になる[68:22〜69:22]
- これは AI による検索での参照(LLMO)の対策にもなる。ある調査で、AI が参照するメディアとして note が YouTube に次いで2位、AI からの流入への期待値が検索の4.2倍、と紹介[69:22〜69:53](出典は確かめていない)

## 8. リピーター・ファンを増やす方法

- 口コミが最強の集客。狙っては起こせないが、期待を超えたときに起きやすい[69:53〜71:23]
- 読んだ直後の感想より、「実際にこう変わった」という変化の口コミを重視する。特典で口コミを頼むと、読後すぐの感想しか集まらないので、本人はやらない[71:53〜73:57]
- 売って終わりにせず、読者の質問とつまずきを記事に足し続ける(リライトを超えて「新築」レベル)。月1回の質疑応答のライブ配信も[81:10〜82:13]
- 買ってくれた人を名簿にする(公式 LINE など)。次に何か出したときに買い、口コミし、副産物につながるのはこの人たち[83:15〜84:17]
- ファンになってもらう魔法はない。期待を超え続けること、誠実であり続けること、接点を切らないこと[84:47〜85:18]

## 9. AI の活用

- AI で誰でも記事を量産できるようになり、低単価の量産の道はさらに報われなくなった。AI を量産に使う人は消耗し、1本を磨くのに使う人は加速する[18:22〜19:23]

## 10. 実際の作業手順(時間軸のロードマップ)[86:49〜91:54]

1. 0 → 月10万円(目安は最初の1〜3か月):土台を決め、プライスファーストで高単価の1本を本気で作り切る。量産・複数の記事・SNS の毎日投稿は捨てる
2. 月10万 → 30万円:作ることから届けることへ。SNS → プロフィール → note・公式 LINE の導線。買った人の名簿を作り始める。副産物にはまだ手を広げない。読者の成功を追い、口コミが回り始める
3. 月30万 → 100万円:リライトで1本を磨き続けて資産にする。副産物を設計する。名簿の読者をファンに育てる。売上が作業時間に比例しなくなる
- 一番やってはいけないのは、フェーズを飛ばすこと(1本もないのに副産物を考える、など)

## 11. 成功のポイント(投稿者の主張)

- 100回書くより、1本を磨く方が強い。量産の記事は書いた瞬間から古くなる消耗品、1本は磨くほど価値が上がる資産[82:13〜82:45]
- 地道に見える道が、一番早く月100万円に届き、一番長く続く[92:26〜92:56]

## 12. 失敗しやすい点・注意点(投稿者の主張)

- note 運営は「ライトに始められる副業」ではなく、実際はとてもむずかしい[85:48〜86:18]
- 買った人を100%成功させるとは言えない(買い切りで、行動するかは見えない)。「全員必ず成功」と言う発信者は疑った方がよい[25:30〜26:02]
- 煽りのタイトル、派手な見出し画像、強引な売り込みは、信頼を削り、合わないお客さんを呼ぶ
