## 9. AI の活用

- Claude Code(AI エージェント):パソコンのフォルダの中のファイルを読み書きできる。普通のチャットと違い、指示を「指示書」というファイルに書いて置いておけば、毎回それを読んでから書いてくれる[01:53〜02:35]
- 指示書に書くこと:読者像、トーン、記事の構成、字数の目安、使ってほしくない言葉(例:「絶対に成績が上がる」のような煽り)、最後の案内のしかた、自分ならではの考え方[02:35、07:40〜08:11]
- 指示書は自分で一から書かなくてよい。箇条書きのメモを渡して、Claude Code に整えさせる[06:39〜07:40]
- 書き方を覚えさせる材料:お客さんやフォロワーによく聞かれる質問への自分の答え(デモでは50問分)。考え方とトーンの材料になり、記事のネタにもなる[05:38〜06:39]
- 「スキル」:一連の作業手順を Claude Code に保存させると、次からは一言で同じ流れを回せる[13:49〜14:20]
- Claude in Chrome(Chrome の拡張機能):ブラウザを動かして、note の下書きにタイトルと本文を入れる。ログインは人が手で行う[11:51〜12:48]
- 使い分け:見た目や画像が絡むなら Codex、段取りや自動の処理なら Claude Code、くらいでよい[03:05]

## 10. 実際の作業手順

1. 投稿ネタを決める:過去の発信やメモをフォルダに入れる。方針は人が決める
2. 自分の書き方を教える:メモと質問への答えから、Claude Code に指示書(md ファイル)を作らせて保存する
3. 本文を書かせる:「このフォルダの私の情報と指示書を使って note の記事を書いて」。デモでは Claude Code がテーマまで自分で選び、約2,500字の記事を書いた[08:42〜09:13]
4. 品質を確かめる:Claude に「別の編集者の視点で、事実・誇大表現・読みにくさをチェックして」と頼み、直させる。事実は、違和感のある所(とくに固有名詞・数字・最新の情報)だけでも、人が一次情報で確かめる[10:16〜11:47]
5. note に下書きで入れる:Claude in Chrome で下書き保存まで。公開ボタンと最後の確認は人が行う[11:51〜13:19]
6. ここまでの流れをスキルにして保存する

## 11. 成功のポイント(投稿者の主張)

- 指示書を一度作れば、毎回指示を打たなくても品質がそろう。使い回せる資産になる[08:11]
- 出てきた記事は完成品ではなく叩き台。人が読んで直す一手間が質を分ける[09:45]
- いきなり完璧な自動化を目指さず、まず指示書を1枚書き、1本だけ作って事実を確かめて出してみる[17:28]

## 12. 失敗しやすい点・注意点(投稿者の主張)

- 規約:ブラウザの自動操作で記事を大量に投稿するのは、プラットフォームの規約やスパム対策に触れる可能性がある。だから下書きで止める。やるなら最新の規約を自分で確かめる[13:19、15:55]
- AI は事実を平気で間違える。AI のファクトチェックも完璧ではない[11:16、15:55]
- AI で書いたとわかるように配慮することも大切になる[16:25]
- 質の低い記事を大量に出すと、読者とプラットフォームの信頼を失う。それは資産ではなく負債[16:25〜16:57]
