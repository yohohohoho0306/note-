# note 収益化の調査(YouTube 動画の分析と蓄積)

note で収益を上げる方法を、YouTube の最近の動画から学び、味のたねあかしに落とし込むための調査記録です。
動画を足したときにも横断分析をやり直せるよう、1本ずつ同じ型でため込みます。

## ファイルの構成

```
research/README.md                この説明と、分析した動画の一覧
research/note_platform_2026.md    note の現状(手数料・機能・公式データ)。動画の情報が古くないかの判断材料
research/food_genre_on_note.md    note の料理ジャンルの先行例と市場の手がかり
research/youtube/日付_動画ID.md    動画1本ごとの分析ノート(公開日_ID)
research/cross_analysis.md        複数の動画の横断分析(共通点・相反点・信頼性・再現性)
research/monetization_models.md   収益化モデルの比較と、AI による自動化の検討
strategy/                         味のたねあかしに落とし込んだ戦略(成果物①〜⑩)
```

## 調べ方の決まり

- 対象:note の収益化を扱う、2026年5月以降に公開された動画を中心にする。前編・後編やシリーズ、コラボの相手側の動画は、まとめて読む
- 読み方:YouTube の自動字幕(文字起こし)を全文読む。タイトルや概要欄だけで判断しない
- 取り方:`python3 tools/fetch_transcripts.py 動画ID …` で、字幕と概要欄を research/記録json/<動画ID>.json に1本ずつ保存する(yt-dlp を使い、ブラウザは使わない)。1本ずつ間をあけて取り、確認画面が出たら回避はせずに待つ。字幕は著作物でこのリポジトリは公開なので、記録json は git に入れない(.gitignore 済み)
- 1本ごとに、同じ12項目(主張、収益の仕組み、手法、テーマの選び方、価格、集客、SEO・SNS、ファン化、AI 活用、作業手順、成功のポイント、注意点)で整理する。動画が触れていない項目は「動画では説明なし」と書く
- 数字・実績・ツールは表にし、「本人の申告/画面で示した証拠/投稿者の推測/出典不明の数字」を区別する。必要なら [分:秒] で場所を残す
- 動画の内容と、分析者(Claude)の評価は分けて書く。評価は「分析者のメモ」の見出しの下だけに書く
- 投稿者の主張を正しいと決めつけない。note 公式の情報(note_platform_2026.md)と食い違う所や、古い可能性がある所は指摘する
- 動画を追加したら、下の一覧に行を足し、cross_analysis.md を見直す

## 動画の選び方(2026-10-30 の調査)

- YouTube で「note 収益化」「note 稼ぎ方」「note 有料記事 売れる」「note メンバーシップ 収益」「note AI 記事 稼ぐ」「note 副業 2026」「note 集客 SEO」「note アフィリエイト」「note 初心者 月1万円」「note 運用 最新」「note 料理 レシピ 収益」などをアップロード日順で検索し、192本の候補を集めた
- 2026年5月以降に公開され、note の収益化を正面から扱うものから、次の観点が偏らないように20本を選んだ:総合ロードマップ、検証(実際の数字)、売れるテーマと記事の設計、AI 活用、メンバーシップ・アフィリエイト・集客
- 外したもの:note 以外の話題(スマホの「Redmi Note」、中国語の SEO 動画など)、2026年4月以前のもの、内容の重なりが大きいもの、極端に短いもの
- 料理・レシピで note の収益化を扱う最近の動画は、見つからなかった
