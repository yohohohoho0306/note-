# 需要と相場の調査の記録

有料記事のテーマ・価格や、連載の回の優先順位を決めるための調査を、1回ごとに1ファイルでためます。

## ファイル名

- 「日付_テーマ.md」(例:2026-11-02_塩加減.md)

## 書くこと

- 調べた日と、調べた場所(note の「有料の記事」の検索、X、Threads、質問箱など)
- 検索した言葉
- note の有料記事:同じテーマの記事の件数、価格の幅(安い〜高い)、多い価格帯
- SNS:反応(いいね・ブックマーク・保存)の多かった投稿の「悩み」と「なぜ反応が多かったか」の要点
- わかったこと(どの悩みが多いか、どの価格なら相場に合うか)と、次に試すこと

## 決まり

- 他の人の投稿や記事の文章は、そのまま写さない。要点を自分の言葉で書く
- 人の名前・アカウント名は、必要なときだけにする(公開のリポジトリなので)
- 数字は、見た日と場所といっしょに書く(あとで変わるため)
