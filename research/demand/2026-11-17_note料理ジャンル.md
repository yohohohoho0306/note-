# note の料理ジャンル:傾向と戦う余地(2026-11-17)

「みんなが何を知りたいのかわからない」を解くための調査です。note の中で、料理の記事がどう読まれ、何が売れているかを数字で見ました。

## 調べた日と場所

- 調べた日:2026-11-17
- 場所:note の検索(スキの多い順に各60本)、ハッシュタグの件数、記事ごとの「高評価」の人数、note 公式の発表、Google 検索(2語)
- 「高評価◯人」は、有料記事を買った人のうち評価をつけた人の数。買った人の数そのものではなく、少なくともこれだけは売れているという下限の目安

## 1. note 全体の傾向(公式の発表)

- 有料記事の売上は前年同月比 +26.8%、メンバーシップは +81.3%(2025年11月)
- 公式の分析で使われた14カテゴリに「料理・食」はない。note の中で料理の有料市場は小さいと見るのが自然
- 売れている記事の平均価格:実用ノウハウ系 1,842円、読み物系 983円。文字数と売上の相関はほぼゼロ
- 出典:[note 公式 有料記事分析 2026-01](https://prtimes.jp/main/html/rd/p/000000360.000017890.html)

## 3. 「失敗の言葉」は note の中では検索されていない

- 「水っぽい」「パサパサ」「味が決まらない」「生焼け」で検索すると、上位は料理と関係ない記事。料理の記事は、スキ100〜200ほどで止まる
- Google で「ハンバーグ 割れる 原因」「野菜炒め 水っぽくなる 理由」を調べると、上位は大手のレシピサイトやニュースサイト。個人の note は出てこなかった(2語だけの確認)
- 反対に、気持ちのこもった失敗談は強い
  - 「レシピどおりに作っても上手にならない。料理がおいしくなる"しくみ"を知ればよかった」という体験記:スキ約2,000
  - 料理への苦手意識を書いたエッセイ:スキ約1,000
- 調味料メーカーが開いた「料理のしくみを学び直す」講座には、定員100名に700名以上の応募があった([発表資料](https://www.zaikei.co.jp/releases/3310852/))。しくみを知りたい人は確かにいる

→ note では「〇〇が割れる原因」という検索向けの形より、「レシピどおりなのにうまくならない」という悩みの語りが読まれる。

わかったこと
- 売れているのは「冷蔵庫に貼れる・すぐ使える」保存版と、健康の悩み。理屈を深掘りした有料記事は売れていない
- 売れている新しい書き手は、記事が数本しかなくても、Threads など note の外から人を連れてきている
- 100〜300円の低い値段でも、書き手のファンがつけば毎回50人以上が買う例がある

## 5. ここから考えたこと(分析者の見立て)

- 戦う余地はある。ただし「理屈を有料で売る」形では勝てない(確信度:おそらく)
- 理屈は無料で読ませて信頼をつくり、お金をもらうのは「使える形」(失敗の逆引き帳など)にするのが合う
- 「プロの引き算」(店ではこうするけど、家ならここは省いていい)は、大手のレシピサイトや AI の解説にない強み
- note の検索だけでは人が来ない。Threads をどう使うかで結果が大きく変わる
