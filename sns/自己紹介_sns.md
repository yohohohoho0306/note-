# はじめましての投稿案(Threads・X)

本人の考え方.md(note のプロフィール)にある言葉だけで作った案です。数値は「15年」だけ。投稿するかどうか、言い回しの直しは本人が決めます。

## Threads(はじめましての投稿・固定する投稿の候補)

はじめまして、たいしょうです。
洋食・ビストロやカフェの厨房に立って15年の料理人です。

お客さんによく聞かれるんです。「なんでこれ、おいしいの?」って。
聞かれると、つい話したくなってしまう酒好きです(笑)

ここでは、塩の振り方や火加減、旬の食材の扱い方など、料理の「なぜ?」を、家の台所で試せる形でお話ししていきます。
レシピどおりに作ったのに味が決まらない…という方に届いたら、うれしいです。

note で連載『味のたねあかし』を始めます。
